# DSA Lab 11

This repository contains implementations of Binary Heap applications using C++.

## Tasks

### Task 1: Huffman Coding
- Construct a Huffman Tree using a Binary Min Heap
- Generate Huffman codes through preorder traversal

File: `task1_huffmanCoding.cpp`

### Task 2: Merging K Sorted Linked Lists
- Merge K sorted singly linked lists
- Use a Binary Min Heap to efficiently select the smallest available node

File: `task2_mergingLists.cpp`

## Compilation

Compile using G++:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic task1_huffmanCoding.cpp -o task1
g++ -std=c++17 -Wall -Wextra -pedantic task2_mergingLists.cpp -o task2
